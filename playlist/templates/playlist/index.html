About the Data

  • 550K Spotify Songs
    Recommendations are drawn from Serkan Tüysüz's 550K Spotify Songs: Audio, Lyrics & Genres dataset on Kaggle
  • Computed at Import
    Each song's pace is calculated once from its tempo (BPM) when the dataset is loaded, not on the fly.
  • No Live API Calls
    StrideSync never queries the Spotify API at runtime — all song data lives in our own database.
